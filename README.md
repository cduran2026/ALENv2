# ALEN — Etapa 3: Diseño visual

Propuesta navegable y responsive que aplica una primera dirección visual completa sobre la arquitectura aprobada de la Home de ALEN.

## Ejecutar localmente

Requisitos:

- Node.js.
- pnpm.

Desde esta carpeta:

```bash
pnpm install
pnpm dev
```

Abrir la URL local indicada por la terminal, normalmente:

```text
http://127.0.0.1:5173/
```

## Compilar

```bash
pnpm build
```

## Alcance

El wireframe incluye:

1. Header persistente.
2. Hero.
3. Problema / oportunidad.
4. Servicios de consultoría.
5. ALEN Control.
6. Cómo funciona.
7. Demostración visual con datos ficticios.
8. Inteligencia Artificial asistencial.
9. Pensado para.
10. Proyectos y experiencia.
11. Liderazgo — Mauricio Retamal.
12. Equipo multidisciplinario.
13. Contacto sin envío real.
14. Footer.

## Límites de esta etapa

- No existe backend.
- El formulario no transmite datos.
- La IA es una representación conceptual.
- La demo no utiliza información real de clientes.
- ALEN Control continúa como nombre provisional.
- Fotografías, biografías, proyectos, datos de contacto y textos legales permanecen sujetos a validación.
